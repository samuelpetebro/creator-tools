# QA pass — 2026-09-17

Scope: catalog/navigation, compressed image header validation, existing automated media-state tests, native file picker accessibility, and metadata export source consistency. This is not complete device certification or a new end-to-end test of every encoder.

Findings fixed:
- Invalid or unavailable localStorage could prevent the home catalog from rendering. Validate supported language keys and tolerate read/write failures.
- Search depended on accents and the current UI language. Normalize accents and index both translated names/descriptions.
- Category filters had incomplete tab semantics. Use a button group with aria-pressed, and explicitly label the search box.
- 20 hidden native file inputs were absent from keyboard navigation. Visually conceal them while preserving their native labels, focus and disabled behavior. Enclosing labels show focus outlines. Shared stylesheet cache updated.
- Metadata Cleaner accepted a replacement file while an asynchronous export was running. Lock the input/drop handling and use a captured source for image data and format/size until completion.

Checks performed before deployment:
- Local HTML asset/link references, respecting base href: no missing destinations.
- Catalog: 17 tools with existing target pages and viewport metadata.
- Syntax checks: all 31 JS files.
- Existing cropper-state, thumbnail-layout, subtitle-format, GIF-settings and image-dimensions suites passed. Cropper's deliberate mock failure produces a console error as part of its successful failure-cleanup test.
- New catalog regression tests cover blocked read/write storage, invalid keys (including inherited object keys), bilingual accent-insensitive search and filter state.
- New metadata regression test replaces the file during pending decode and confirms original output type/size and unlocked completion.

Live browser checks are recorded in the associated pull request. Physical iPhone/Android tests, peak memory and download delivery across devices remain pending. Responsive CSS inspection alone is not a physical mobile test.
