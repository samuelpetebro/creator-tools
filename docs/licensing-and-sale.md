# Licensing and future-sale note

Updated: 2026-09-18

Droop's repository is currently published under the MIT License.

## What that means

- Copies already received under MIT keep the permissions granted by that license.
- Removing or replacing the repository license later does not retroactively take those permissions away from copies already distributed.
- The copyright owner can choose different terms for future versions or for new proprietary code they own, but that does not make already-distributed MIT copies exclusive again.
- A future buyer can still acquire the domain, brand, infrastructure, accounts, current source, future development rights and other assets that are actually transferred. The seller should not describe the historical MIT-distributed code as exclusive.

## Practical rule for Droop

Before any sale that promises exclusivity:

1. inventory exactly what assets are being sold;
2. distinguish previously MIT-distributed source from later proprietary assets/code;
3. preserve third-party license notices and review dependency licenses;
4. put ownership, representations and transfer terms in the sale agreement;
5. get qualified legal review for the transaction rather than relying on this project note.

This document is a project-risk note, not legal advice.
